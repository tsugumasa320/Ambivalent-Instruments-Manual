# Delay Expander - Tap Tempo & Sync for Delay

Tap tempo and sync expander for the Ambivalent Instruments Delay module.

## Features

- Tap tempo button for setting delay time by rhythm
- Sync mode toggle for tempo-quantized delay
- Reset button and trigger input
- External clock sync input
- Clock output reflecting current delay tempo
- Compact 2HP panel

## Documentation

- [English Manual](manual.md) - Complete user guide in English
- [日本語マニュアル](manual_jp.md) - 日本語での詳細ガイド

## Quick Start

1. Place Delay Expander directly to the right of the Delay module
2. Tap the Tap button repeatedly to set delay time from your rhythm
3. Use Sync On to quantize the delay time to musical divisions
4. Connect an external clock to the Sync input for automatic tempo lock

For detailed instructions, see the full manual pages linked above.
