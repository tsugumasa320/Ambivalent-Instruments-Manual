# Crackl

Inspired by *Velvet Sunset* by **manual** (the artist), this small noise generator adds a touch of warmth and melancholy behind beautiful harmonies. With its delicate texture and understated presence, it blends a sense of transience into patches and performances.

## Features

- Three independent voices, each combining a morphing oscillator with sample-and-hold noise modulation
- Per-voice frequency (slider), harmonics, noise-mod depth, and level
- Shared drive, fractional modulo wrap, and sample-rate / bit-style degradation before the mono mix bus
- Dedicated CV on harmonic, noise-mod, frequency, and per-voice gain paths (where applicable)
- Mono output scaled for Rack audio levels

## Quick Start

1. Add **Crackl** from the **Ambivalent Instruments** plugin
2. Set the three vertical **Freq** sliders to taste, then balance **Gain A/B/C**
3. Open up **Noise Mod** per voice for grain; use **Drive** and **Modulo** for grit and wrap
4. Use **Sample rate** (left = cleaner internal ratio, right = stronger degradation) and **Out** for final level

For parameter ranges and CV behavior, open the full manuals above.
